# Roadmap

1. Gate 1: scaffold, contracts, discovery, redaction, AA001, JSON, CLI.
2. Gate 2: complete Python static engine, fixtures, terminal output, coverage.
3. Gate 3: structured GPT-5.6 judgment, review/plan, HTML, MCP.
4. Gate 4: README, acceptance runner, self-scan, demo, authorized live smoke test.
5. Stretch after Gate 3: TypeScript, GitHub Actions, judgment-enabled MCP.
6. Production 1.0: Report 2.0, robustness defects, stable baselines, SARIF, and engine evidence quality.
7. Reference MCP: bounded local stdio plus stateless hosted Streamable HTTP with typed tools.
8. Product access: functional Sites landing/connect surface and approval-gated Cloud Run deployment.
9. Release gate: cross-platform CI, compliance artifact, and zero-finding production self-scan.
10. Batch 2: cross-vendor Python adapters, TypeScript subset, Report 2.2, and interactive HTML review.
